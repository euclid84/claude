# 설치 가이드 (약 20분)

관리자(시트 소유자) 기준입니다. 한 번만 하면 됩니다.

## 1. 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 `우리가족 진료기록`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.

## 2. 코드 붙여넣기 (파일 2개)

PC에서 하는 것을 권장합니다. 저장소의 `dist/` 폴더에 붙여넣기용 파일 2개가 있습니다.

1. GitHub에서 `dist/Code.gs` 열기 → 오른쪽 위 **복사 버튼(Copy raw file)** 클릭
2. Apps Script 편집기 왼쪽 `Code.gs` 클릭 → 안에 있던 내용을 전부 지우고 붙여넣기 → 💾 저장
3. 왼쪽 **파일 옆 + → HTML** → 이름을 `Index` 로 입력 (`.html`은 자동으로 붙음)
4. GitHub에서 `dist/Index.html` 열기 → 복사 버튼 → 새로 만든 `Index` 안의 내용을 전부 지우고 붙여넣기 → 💾 저장

저장한 뒤 시트 탭으로 돌아가 **새로고침(F5)** 하면 상단 메뉴에 `🩺 진료기록 관리`가 생깁니다.

> 개발자용: `apps-script/` 폴더가 원본입니다. 원본을 고친 뒤 `scripts/build.sh`를 실행하면 `dist/`가 다시 만들어집니다. [clasp](https://github.com/google/clasp)로 `apps-script/`를 그대로 올려도 됩니다.

## 3. 초기 설정

1. `🩺 진료기록 관리 → 1. 초기 설정` 실행 → 권한 승인 창이 뜨면 승인
   (고급 → "안전하지 않은 페이지로 이동" → 허용. 본인이 만든 스크립트라서 뜨는 경고입니다.)
2. 시트 `Config`, `DoctorPresets`, `Users`, `Records`, `Chats`, `DoctorProfiles`, `AuditLog` 가 생기고, 드라이브에 사진 폴더가 생깁니다.
3. 완료 창에 나오는 **초대코드**를 적어둡니다. (Config 시트에서도 확인 가능)

## 4. Gemini API 키 등록

1. [Google AI Studio](https://aistudio.google.com/apikey) 에서 API 키 발급
2. `🩺 진료기록 관리 → 2. Gemini API 키 등록` 에 붙여넣기 (시트가 아닌 스크립트 속성에 저장됩니다)
3. 건강 정보이므로 AI Studio에서 **결제(Billing)를 연결한 프로젝트의 키**를 권장합니다.
4. Config 시트의 `GEMINI_MODEL` 값이 AI Studio에서 사용 가능한 모델명인지 확인하세요. (기본 `gemini-2.5-flash`)

## 5. 웹앱 배포

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**
2. 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (앱 자체 아이디/비번으로 보호되므로 구글 로그인 불필요)
3. 배포 → 나오는 `https://script.google.com/macros/s/…/exec` 주소가 앱 주소입니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전** 으로 다시 배포해야 반영됩니다. (주소는 그대로)

## 6. 휴대폰에 앱처럼 설치

- **안드로이드(크롬)**: 앱 주소 열기 → ⋮ → **홈 화면에 추가**
- **아이폰(사파리)**: 앱 주소 열기 → 공유 → **홈 화면에 추가**

## 7. 관리자와 가족

이 앱은 **가족 각자가 자기 기록을 관리하고, 관리자가 온 가족을 챙겨보는** 구조입니다.
가족 구성과 권한은 코드나 시트를 고치지 않고 앱의 **⚙️ 설정 → 🛠 관리자 콘솔**에서 정합니다.

1. **관리자가 먼저 가입**합니다. 처음 가입한 사람이 자동으로 관리자가 됩니다.
2. 가족(아내, 장모님, 장인어른 …)에게 앱 주소 + 초대코드를 보냅니다. 각자 **직접** 아이디/비밀번호를 정해 가입하고, 복구코드를 적어 보관합니다.
   - 가입 화면에 "관리자가 함께 본다"는 안내가 나오고, 로그인하면 **관리자에게 자동으로 연결**됩니다.
   - 가족끼리는 기본적으로 서로의 기록을 볼 수 없습니다.
3. **🛠 관리자 콘솔**에서:
   - **👥 가족 구성원**: 누가 가입했는지 보고, **관리자로 지정/해제** (예: 아내를 공동 관리자로). 지정하면 그 즉시 가족 전체가 연결됩니다. 관리자는 최소 1명이어야 합니다.
   - **🔐 조회 권한**: "누구의 기록을" 고른 뒤 다른 가족마다 **안 보임 / 보기 / 보기+등록**을 누릅니다. (예: 장모님 기록 → 장인어른 "보기", 장인어른 기록 → 장모님 "보기")
   - **⚙️ 가입 설정**: 새 가입 허용 켜기/끄기, 초대코드 확인·새로 만들기. 가족 가입이 끝나면 가입 허용을 꺼두세요.
4. **앱을 안 쓰실 가족**(예: 아빠)은 **👪 가족 관리 → 대신 관리할 가족 추가**로 프로필을 만들고 결과지를 대신 올립니다. 나중에 본인이 쓰고 싶어 하시면 **관리 → 본인 계정 만들어 드리기**.
5. **📋 가족 한눈에 보기**로 모두의 최근 기록과 확인할 항목을 점검합니다.

> 조회 권한은 "안 보임"으로 바꾸는 즉시 서버가 막습니다. 새로 가입한 가족은 **한 번 로그인한 뒤**부터 권한을 줄 수 있습니다 (암호 열쇠가 그때 만들어지기 때문).

> **상담 내역 공유 규칙**
> - 관리자는 가족이 직접 나눈 상담도 **"👤 가족 상담"** 탭에서 읽을 수 있습니다 (가입 화면에서 안내됨).
> - 관리자가 가족 기록에 대해 나눈 상담은 가족에게 보이지 않습니다. 알려드리고 싶은 답변만 **📤 보내기**를 누르면 가족 화면에 "👪 가족이 보내준 설명"으로 나타납니다.

## 8. 의사 선생님 프롬프트 작성 (관리자)

AI에게 들어가는 지시문은 아래 순서로 조립됩니다. `설정 → 의사 선생님 설정 → 최종 프롬프트 미리보기`로 확인할 수 있습니다.

| 순서 | 어디서 | 누가 | 내용 |
|---|---|---|---|
| 1 | 코드(`Gemini.gs`의 `SAFETY_PROMPT`) | 고정 | 진단 대체 금지, 약 임의 변경 금지, 응급 시 119 등 안전 원칙 |
| 2 | `Config` 시트 `BASE_DOCTOR_PROMPT` | 관리자 | 모든 가족에게 공통인 의사 선생님 성격 |
| 3 | `DoctorPresets` 시트 | 관리자 | 이름 붙인 프리셋 (예: "장모님용 내과 선생님"). 사용자가 앱에서 선택 |
| 4 | 앱의 질문지 | 사용자 | 말투/수준/길이, 호칭·나이대·질환·복용약·걱정거리 |
| 5 | 앱의 "추가 지시사항" | 사용자 | 자유롭게 작성 |

프리셋을 추가하려면 `DoctorPresets` 시트에 행을 추가하세요: `preset_id`(영문, 겹치지 않게), `name`(앱에 보이는 이름), `prompt`, `active`(TRUE/FALSE).

## 관리자 메뉴

- **초대코드 새로 만들기**: 기존 코드 무효화
- **계정 잠금 해제**: 비밀번호 5회 틀려 15분 잠긴 계정 즉시 해제 (기록은 볼 수 없음)

## 시트에 보이는 것 / 안 보이는 것

| 관리자가 시트에서 볼 수 있는 것 | 볼 수 없는 것 (암호문) |
|---|---|
| 아이디, 가입일, 마지막 로그인, 기록 개수, 저장 시각, 누가 누구의 보호자인지 | 결과지 내용, 날짜·병원·진단·수치, 사진, 상담 내역, 의사 설정/건강정보 |

## 보안 한계 (솔직하게)

- 앱 코드는 관리자가 배포합니다. 관리자가 **코드를 악의적으로 고치면** 비밀번호를 가로챌 수 있습니다. 이 구조는 "시트를 열어봐도 내용이 안 보인다"를 보장하는 것이지, 코드를 고칠 수 있는 사람까지 막지는 못합니다.
- AI 분석/질문 순간에는 원문이 Apps Script를 거쳐 Gemini로 전달됩니다 (저장하지는 않음).
- 로그인은 최대 6시간 유지되며, 새로고침하면 다시 로그인해야 합니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "관리자가 아직 Gemini API 키를 등록하지 않았습니다" | 4단계 다시 |
| "AI 호출에 실패했습니다 (코드 404)" | Config `GEMINI_MODEL` 모델명 확인 |
| "AI 호출에 실패했습니다 (코드 400/403)" | API 키 확인, Apps Script 편집기 → 실행 로그 확인 |
| 코드를 고쳤는데 앱이 그대로 | 5단계 "새 버전"으로 재배포 |
| "내용이 너무 깁니다" | 원문 텍스트를 줄이거나 기록을 나눠 저장 (시트 셀 5만자 한도) |
