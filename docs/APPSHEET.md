# 앱시트(AppSheet)는 왜 주 화면으로 쓰지 않았나

처음 요청은 "구글시트 + 코드 + 앱시트"였지만, 아래 두 요구사항이 앱시트와 **동시에 만족될 수 없어서** 화면은 Apps Script 웹앱으로 만들었습니다.

1. **본인이 정한 아이디/비밀번호로만 로그인**
2. **관리자(나)도 장모님 기록을 볼 수 없어야 함**

## 앱시트의 제약

| 항목 | 앱시트 | 이 프로젝트(Apps Script 웹앱) |
|---|---|---|
| 로그인 | 구글/마이크로소프트 등 **계정 로그인만** 지원. 자체 아이디/비번은 공식 기능이 아님 | 자체 아이디/비번 |
| 사용자별 분리 | Security Filter(`[email] = USEREMAIL()`)로 가능 | 서버에서 세션별로 분리 |
| 관리자가 내용 열람 | **가능.** 앱시트는 시트의 평문을 읽어야 하므로 시트 소유자는 모든 내용을 봄 | **불가능.** 시트에는 암호문만 저장 |
| 사진 촬영/업로드 | 매우 편함 | 가능 (카메라/앨범) |
| 홈 화면 설치 | 앱시트 앱 | 브라우저 "홈 화면에 추가" |

앱시트는 데이터를 기기로 동기화해서 화면에 그리기 때문에, 시트에 암호문을 넣으면 앱시트 화면에도 암호문만 보입니다. 즉 "앱시트로 보기"와 "관리자도 못 보기"는 서로 충돌합니다.

## 그래도 앱시트를 쓰고 싶다면 (선택지 B)

"관리자는 볼 수 있어도 괜찮다"로 조건을 완화할 수 있다면 앱시트 버전도 가능합니다.

- 장모님은 본인 **구글 계정**으로 로그인
- 기록 테이블에 `owner_email` 열 + Security Filter `[owner_email] = USEREMAIL()`
- 사진은 Image 열, Gemini 분석/질문은 앱시트 Automation → **Apps Script 호출**(이 저장소의 `Gemini.gs` 로직 재사용)

이 경우 장모님끼리/가족끼리는 서로 못 보지만, **시트 소유자인 관리자는 모든 기록을 볼 수 있습니다.** 원하시면 이 버전도 만들어 드릴 수 있습니다.
