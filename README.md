# 🩺 우리가족 진료기록

병원 진료 결과지(사진·문자·건강검진표·처방전)를 등록하고, **Gemini AI 의사 선생님**에게 결과를 물어볼 수 있는 가족용 앱입니다.
구글 스프레드시트 + Apps Script 만으로 동작하며, 휴대폰 홈 화면에 앱처럼 추가해서 씁니다.

## 핵심 기능

| 기능 | 설명 |
|---|---|
| 본인 아이디/비밀번호 | 각자 정한 아이디·비밀번호로만 로그인. 초대코드가 있어야 가입 가능 |
| **종단간 암호화** | 기록·사진·상담내역은 브라우저에서 본인 비밀번호로 암호화된 뒤 저장 → **시트 소유자(관리자)도 내용을 볼 수 없음** |
| 다양한 결과 형태 | 결과지 사진(여러 장), **PDF 파일**(건강검진 결과 등, 1개 최대 10MB), 문자/카톡 알림 붙여넣기, 직접 입력. 종류: 정기건강검진·외래진료·입원·수술·검사결과·처방·약·문자·알림·기타 |
| AI 자동 정리 | Gemini가 사진/문자를 읽어 날짜·병원·진단·검사수치(정상/높음/낮음)·처방약·다음 예약을 표로 정리 → 확인 후 저장 |
| 문자 대화 캡처 일괄 등록 | 병원 문자 화면 여러 장(최대 10장)을 올리면 날짜별 기록으로 나눔. "그저께/(목요일)" 같은 상대 날짜 변환, 겹친 캡처·이미 등록된 기록 중복 제거, 예약·알림 문자 분리, "SGOT/PT 30/40" → AST·ALT 분리 |
| 👑 관리자 중심 가족 관리 | 가족 각자가 자기 기록을 등록·확인하고, **관리자**(예: 아들·사위·남편)는 가족 모두의 기록을 함께 봄. 가족이 가입하면 관리자에게 **자동 연결**되고, 가족끼리는 서로 볼 수 없음. 관리자 화면의 **📋 가족 한눈에 보기**로 모두의 최근 기록·확인할 항목 점검 |
| 🧓 대신 관리하는 가족 | 앱을 안 쓰시는 가족(예: 아빠)은 관리자가 프로필을 만들어 결과지를 대신 올림. 나중에 본인이 쓰고 싶으면 아이디·비밀번호를 만들어 넘겨줌(기록 유지) |
| 💬 상담 공유 | 관리자는 가족 본인의 상담도 읽을 수 있고, 관리자 상담 중 골라서 **📤 보내기** → 가족 화면에 "가족이 보내준 설명"으로 표시 |
| AI 의사 선생님 Q&A | 기록 1건 또는 전체 기록을 바탕으로 질문. 말투·설명 수준·내 건강정보·추가 지시사항 반영 |
| 의사 선생님 설정 | ① 관리자 공통 프롬프트(Config 시트) ② 관리자 프리셋(DoctorPresets 시트) ③ 사용자 질문지 ④ 사용자 추가 지시사항 — 4단계로 조립 |
| 수치 추이 | 같은 검사 항목(예: LDL 콜레스테롤)을 날짜별로 비교하는 그래프 |
| 비밀번호 분실 | 가입 때 1회 보여주는 복구코드로 재설정 (기록 유지) |

## 구조

```
휴대폰 브라우저 (Apps Script 웹앱)
 ├─ 비밀번호 → PBKDF2 → 암호화 키 (브라우저 메모리에만 존재)
 ├─ 사진/문자 원문 ──────────────▶ Apps Script ──▶ Gemini API (분석/질문, 저장 안 함)
 └─ 암호화된 기록/사진/상담 ─────▶ Apps Script ──▶ 구글 시트 / 구글 드라이브 (암호문만 저장)
```

| 파일 | 역할 |
|---|---|
| `apps-script/Code.gs` | 웹앱 진입점, 초기 설정, 스프레드시트 관리자 메뉴, 설정값 |
| `apps-script/Db.gs` | 시트를 테이블처럼 읽고 쓰는 도우미 |
| `apps-script/Auth.gs` | 가입/로그인/잠금/비밀번호 변경/복구코드 |
| `apps-script/Records.gs` | 기록·사진·상담·의사설정 저장 (본인 또는 권한 받은 보호자만 접근) |
| `apps-script/Shares.gs` | 가족 공유·관리자 연결·대신 관리 프로필 — 공개키로 데이터키 전달, 권한 확인 |
| `apps-script/Gemini.gs` | 결과지 분석, Q&A, 의사 선생님 프롬프트 조립 |
| `apps-script/Index.html`, `App.html`, `Crypto.html`, `Styles.html` | 모바일 화면 |

설치 방법: **[docs/SETUP.md](docs/SETUP.md)**
자동 테스트: `./scripts/build.sh && cd tests && npm install && npm test` (가짜 구글시트 + 실제 브라우저로 가입·공유·권한을 검사)
앱시트(AppSheet)에 대해: **[docs/APPSHEET.md](docs/APPSHEET.md)**

## 꼭 알아둘 점

- 이 앱의 AI 설명은 참고용이며 진단·처방을 대신하지 않습니다.
- 비밀번호와 복구코드를 **둘 다** 잃어버리면 그 계정의 기록은 누구도 열 수 없습니다.
- 분석/질문 시 원문이 Google Gemini API로 전송됩니다. 건강 정보이므로 **결제가 연결된(유료 등급) API 키**를 권장합니다. 무료 등급은 Google이 데이터를 서비스 개선에 사용할 수 있습니다.
